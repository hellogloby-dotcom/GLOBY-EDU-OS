# Contributing to GlobyEdu OS

This repository is a living blueprint for the platform. Follow these guidelines:

- Fork the repo and open pull requests against `main`.
- Write clear commits and PR descriptions.
- Add tests for new features and run linting.
- Keep PRs focused and < 400 LOC when possible.

Code of Conduct: see CODE_OF_CONDUCT.md
Security reporting: see SECURITY.md
